# Seeds Demo

Esta pasta deve conter apenas massa de demonstracao, como reservas, vendas, estoque ficticio e dados para graficos.

Esses scripts ajudam em apresentacoes e testes manuais, mas nao devem ser executados em producao.

Os scripts antigos em `scripts/postgres/*seed*` ainda foram preservados por compatibilidade historica. A tendencia e mover/copiar apenas os dados demonstrativos relevantes para esta pasta aos poucos.
